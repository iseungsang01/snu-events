# 요청: .ics 내려받기 대신 캘린더에 바로 들어가게

지금 카드의 '캘린더에 추가'는 .ics 파일을 내려받게 해. 받은 파일을 다시 열어야 해서 아무도 안 쓸 것 같아. 두 가지로 바꿔 줘.

1. **카드마다 'Google 캘린더에 추가'**
   - `https://calendar.google.com/calendar/render?action=TEMPLATE` 링크로 새 탭에서 열기. `text`(제목), `dates`(시간 있으면 Asia/Seoul 기준
     `YYYYMMDDTHHMMSS/YYYYMMDDTHHMMSS` 와 `ctz=Asia/Seoul`, 끝 시각이 없으면 1시간짜리, 시간이 없으면 종일 `YYYYMMDD/다음날`),
     `location`(장소), `details`(요약 한 줄 + 원문 링크). 여러 날 행사는 시작~끝 날짜 종일.
   - 기존 .ics 내려받기는 작은 글씨 보조 링크('다른 캘린더(.ics)')로만 남겨.
2. **구독 캘린더(자동 연동)**
   - 수집할 때마다 `docs/calendar/all.ics` 와 종류별 `docs/calendar/<영문키>.ics` (performance, exhibition, contest, lecture, recruit, other)를
     만들어. RFC 5545 준수: `VCALENDAR` 에 `X-WR-CALNAME`(예: "서울대 행사 — 공연"), `X-WR-TIMEZONE:Asia/Seoul`, `VTIMEZONE` 또는 TZID 사용,
     행사마다 고정 `UID`(행사 id 기반, 매일 바뀌지 않게), `DTSTAMP`, `SUMMARY`, `LOCATION`, `DESCRIPTION`(원문 링크), `URL`. 줄 접기·이스케이프 정확히.
   - 페이지 위쪽에 '내 캘린더에 구독' 버튼: 누르면 작은 창에 종류별로
     ① 'Google 캘린더에 구독' 링크 `https://calendar.google.com/calendar/r?cid=` + `webcal://` 주소(인코딩),
     ② 'Apple·Outlook' 용 `webcal://iseungsang01.github.io/snu-events/calendar/<키>.ics` 링크,
     ③ 주소 복사 버튼. 지금 거르고 있는 종류가 있으면 그 종류를 먼저 보여 줘.
   - 한 줄 안내: "구독하면 매일 아침 갱신된 행사가 캘린더에 자동으로 들어옵니다(캘린더 앱마다 반영 주기는 다를 수 있음)."
3. `scripts/update_local.cmd`: 커밋할 때 `docs/calendar/*.ics` 도 함께 add.
4. 테스트: Google 링크의 날짜·시간대 형식(시간 있음/없음/여러 날), ics 파일이 RFC 5545 형식(줄 75옥텟 접기, 쉼표·세미콜론 이스케이프, UID 고정), 종류별 파일 분리.
   가능하면 `icalendar` 라이브러리로 생성·파싱 검증(requirements 에 추가).

`reference/`, `prompts/`, `eval/` 는 건드리지 마. 다 하면 `docs/calendar/` 를 지금 `docs/events.json` 으로 실제로 만들고 pytest 결과를 알려 줘.
