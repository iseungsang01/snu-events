# 요청: 로그인 없는 개인화 — 내 관심 탭과 내 구독 주소

계정 없이 사람마다 다르게 쓰게 하고 싶어. 설정은 서버에 저장하지 않는다.

1. **내 구독 주소(종류 조합)**
   - 수집할 때마다 종류 6개(performance, exhibition, contest, lecture, recruit, other)의 모든 조합 63개에 대해
     `docs/calendar/mix/<키를 정렬해 '-'로 이은 이름>.ics` 를 만든다(예: `lecture-performance.ics`). 전부면 `all.ics` 를 쓴다.
     UID·형식은 앞에서 만든 종류별 ics 와 같게, 같은 생성 함수를 재사용.
   - 페이지의 '내 캘린더에 구독' 창에서 종류를 여러 개 체크하면 그 조합의 주소가 바로 만들어져
     Google 캘린더 구독 링크, webcal 링크, 주소 복사를 보여 준다.
2. **내 관심 탭**
   - 기간 탭 옆에 '내 관심' 탭. 설정 창에서 관심 종류(체크), 관심 키워드(여러 개, 하나라도 제목·본문에 있으면 포함),
     빼고 싶은 말(여러 개, 하나라도 있으면 제외)을 넣는다. 한국어 IME 조합 중 Enter 로 칩이 만들어지지 않게 하고,
     띄어쓰기 차이("글쓰기 상담"/"글쓰기상담")를 무시하고 찾는다.
   - 설정은 이 브라우저의 localStorage 에만 저장(실패해도 페이지가 깨지지 않게 try/catch). '내 관심' 탭은 오늘 이후 행사를 날짜순으로.
   - '설정 링크 복사': 설정을 URL 해시(`#me=...`)에 담은 링크를 복사. 다른 기기에서 그 링크를 열면 설정이 채워진다.
   - 관심 키워드로 걸러진 행사도 카드마다 'Google 캘린더에 추가'는 그대로.
   - 구독 창에서는 "키워드 조건은 페이지에서만 적용되고, 구독 캘린더는 고른 종류 기준"이라고 한 줄로 알려 준다.
3. `scripts/update_local.cmd`: `docs/calendar/` 하위 전부 add.
4. 테스트: 조합 파일 63개 생성과 이름 규칙, 해시 설정 왕복(인코딩/디코딩), 키워드·제외어 매칭(공백 무시, IME 조합 Enter 무시).

`reference/`, `prompts/`, `eval/` 는 건드리지 마. 다 하면 지금 데이터로 실제 생성하고 pytest 결과를 알려 줘.
