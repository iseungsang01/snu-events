# 요청: GitHub Actions 자동 갱신이 중간에 죽었다

배포한 뒤 `update.yml` 을 한 번 돌렸더니 27쪽 목록을 받다가 아래 오류로 실패했어. 26쪽까지는 정상이었어.

```
response = session.get(LIST_URL, params=params, timeout=30)
requests.exceptions.ChunkedEncodingError: Response ended prematurely
```

지금 재시도는 5xx 응답에만 걸려 있어. 연결이 끊기거나 응답이 중간에 잘리는 경우(requests 의 ConnectionError, Timeout, ChunkedEncodingError)에도
같은 간격(2·4·8초)으로 재시도하게 해 줘. 목록과 상세 요청 둘 다. 끝까지 실패하면 지금처럼 기존 `docs/events.json` 을 그대로 두고 실패로 끝나면 돼.

네트워크 없이 검증되는 테스트를 보태고 pytest 결과를 알려 줘. `reference/`, `prompts/`, `docs/events.json` 은 건드리지 마.
