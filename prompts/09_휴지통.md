# 요청: 관심 없는 행사를 버리는 휴지통 (브라우저에만 저장)

예전에 만든 Chrome 확장 '서울대 비교과 한눈에'에 있던 휴지통을 이 페이지에도 넣고 싶어. 관심 없는 행사를 카드에서 치우고, 실수로 버린 건 되살릴 수 있게.

1. **버리기**: 카드마다 작은 '버리기' 버튼. 누르면 그 카드가 목록에서 사라지고, 화면 아래에 몇 초간 '되돌리기' 알림이 뜬다.
   여러 개를 한 번에 버릴 수 있게, 목록 위에 '선택' 모드(카드 체크 → '선택한 n개 버리기')도.
2. **휴지통 보기**: 탭 줄 오른쪽에 '휴지통 n' 버튼. 누르면 버린 행사만 보여 주고, 카드마다 '되살리기', 위에 '모두 되살리기'·'휴지통 비우기'.
   휴지통 보기에서는 기간 탭과 무관하게 버린 행사 전부를 날짜순으로.
3. **저장**: 버린 행사 id 목록을 localStorage 에만 저장(try/catch, 실패해도 페이지는 동작). 끝난 지 30일이 지난 행사 id 는 자동으로 정리해 목록이 계속 커지지 않게.
   기존 '설정 링크 복사'(#me=...)에 버린 목록도 함께 담아 다른 기기로 옮길 수 있게.
4. 모든 보기(오늘·이번 주·다음 주·이번 달·전체·내 관심)와 종류 개수 표시, 검색 결과에서 버린 행사를 뺀다.
5. 구독 캘린더(.ics)는 서버 없이 미리 만든 파일이라 버린 행사가 빠지지 않는다. 구독 창에 이 점을 한 줄로 알려 줘.
6. 테스트: 버리기/되살리기/되돌리기, 30일 정리, 해시 왕복에 버린 목록 포함, 저장소 접근 실패 시에도 렌더링.

`reference/`, `prompts/`, `eval/` 는 건드리지 마. pytest 결과를 알려 줘.
